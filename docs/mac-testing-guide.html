Buyer Bot prototype · user acceptance testing

Testing the buyer bot on your Mac

You'll have a conversation with the bot as if you were a buyer, then read the brief a consultant would receive before calling you. Written for someone who has never opened Terminal.

About 15 minutesMost of it waiting for things to download
Nothing can breakIt only touches its own folder on your Desktop
Two things to typeThe rest is clicking and picking numbers
1

Install Python once, ever

Python is the engine the bot runs on. Installing it is a normal Mac installer — the same as installing Zoom.

  1. Go to python.org/downloads
  2. Click the big yellow Download Python button
  3. Open the file that lands in your Downloads
  4. Click Continue → Continue → Agree → Install, and enter your Mac password when asked
✓ You'll know it worked when the installer says "The installation was successful."
2

Download the bot

  1. Open the project page
  2. Click the green Code button, then Download ZIP
  3. In your Downloads folder, double-click the ZIP file — it turns into a folder
  4. Drag that folder onto your Desktop

The folder has a long name — bot_prototype-claude-buyer-whatsapp-ai-bot-7l201r. You never have to type it.

✓ You'll know it worked when that folder is sitting on your Desktop and opens to show files like README.md and start.command.
3

Open Terminal

Press ⌘ Command + Space, type Terminal, press Enter.

A plain window opens with a blinking cursor. It works like a chat: you type one line, press Enter, and it answers. Nothing happens until you press Enter.

✓ You'll know it worked when you see a window with your computer's name and a % sign waiting for you.
4

Point Terminal at the folder

Terminal needs to know which folder to work in. Type this — including the space at the end — but don't press Enter yet:

Terminal 
% cd ← then drag the folder in

Now drag the folder from your Desktop straight into the Terminal window. It fills in the address for you. Now press Enter.

Why dragging? Because typing that folder name by hand is how this step goes wrong. Dragging can't misspell it.
✓ You'll know it worked when the line before the % now ends with bot_prototype…
5

Start it

Type this and press Enter:

Terminal 
% bash start.command

The first time, this takes a minute or two and prints a lot of scrolling text. That's it installing what it needs — let it run. It only does this once.

✓ You'll know it worked when the scrolling stops and you see a menu with five numbered options.
6

Be a buyer

Type 1 and press Enter. Give it your name, then answer the way a real buyer would.

Don't stick to the options it shows you. The whole point is to find out where it breaks — so say "somewhere near the coast" instead of tapping North Coast, or "around 8 million" instead of picking a budget band. Try Arabic and see what happens; it's English-only for now, and what you type becomes the input for the Arabic build.

✓ You'll know it worked when it shows you matching units and ends by naming the consultant it handed you to.
7

See what your agent would get

Back at the menu, type 2 and press Enter. Your browser opens the dashboard. Find your own name in the lead queue and click the row.

That panel is the product: what the consultant reads before dialling. Judge it the way a sales director would — would this have made the call better?

When you're done looking, go back to Terminal and press Control + C to stop the dashboard. That's the control key, not command.

✓ You'll know it worked when your conversation appears as a lead with a score, a band, and the units you were shown.

The menu, in full

You'll come back to this every time.

5Quit

Stop the dashboardControl + C
Leave properlyChoose 5, then close the Terminal window
Come back laterRepeat steps 3, 4 and 5 — setup doesn't run twice, so it's about ten seconds

If something goes wrong

None of these break anything. Terminal is blunt, not angry.

What you seeWhat to do
command not found: python3 Python isn't installed yet — go back to step 1
no such file or directory The cd line didn't land. Redo step 4 and drag the folder in rather than typing its name
permission denied Make sure you typed bash start.command, with bash in front
The browser doesn't open by itself Type localhost:8000 into Chrome or Safari yourself
"This site can't be reached" The Terminal window has to stay open while the dashboard is running
Terminal looks frozen It's almost always waiting for you — press Enter. To interrupt anything at all, Control + C
Something else entirely Close the Terminal window, open a new one, and start again from step 3. Your test data is kept

What's worth writing down

Wording complaints count as findings. The copy is placeholder and tone-configurable, so "no Egyptian buyer would say it like that" is exactly the kind of note that's useful now.

  • Anything the bot didn't understand — your exact words, and its reply
  • Any question it asked that it should already have known the answer to
  • Any brief where a consultant would still have to ask the buyer something basic
  • Leads scored hot that your floor would call cold, and the reverse

The full test-case list — thirteen of them, including the returning buyer and the opt-out — is in docs/UAT.md inside the folder you downloaded.
