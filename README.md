## Getting Started

### Prerequisites

- Python 3.8+
- pip

### Installation

```bash
git clone https://github.com/sarahnagaty-beep/bot_prototype.git
cd bot_prototype
pip install -r requirements.txt
```

### Usage

```bash
python main.py
```
